# Carpeta APK — LSCTalker v1.0

Deposita aquí el archivo APK generado desde Android Studio.

## Cómo generar el APK (debug)

1. Abre el proyecto en Android Studio
2. Menú: **Build → Build Bundle(s) / APK(s) → Build APK(s)**
3. Espera a que compile (barra de progreso inferior)
4. Haz clic en **"locate"** en el aviso que aparece, o navega a:
   ```
   app/build/outputs/apk/debug/app-debug.apk
   ```
5. Copia ese archivo a esta carpeta y renómbralo:
   ```
   LSCTalker_v1.0_debug.apk
   ```

## Nombre esperado del archivo

```
LSCTalker_v1.0_debug.apk
```

## Instalación en dispositivo

1. Copia el APK al dispositivo Android (USB o Drive)
2. En el dispositivo: **Ajustes → Seguridad → Instalar apps desconocidas**
3. Abre el APK desde el administrador de archivos
4. Requiere Android 13 (API 33) o superior
